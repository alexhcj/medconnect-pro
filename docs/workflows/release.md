# Release Workflow

1. Validate tasks and acceptance criteria.
2. Run lint.
3. Type-check.
4. Unit/integration/API tests.
5. E2E critical workflows.
6. Build frontend/backend.
7. Dependency/security scan.
8. Review migration and rollback implications.
9. Verify environment configuration.
10. Verify synthetic demo data.
11. Deploy to development/staging.
12. Smoke test.
13. Production approval only when the project is actually being deployed to production.
